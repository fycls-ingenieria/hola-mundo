# hola-mundo

Proyecto de ejemplo "Hola mundo", creado siguiendo los [lineamientos de GitHub de Fycls Ingeniería](https://github.com/fycls-ingenieria/lineamientos-github).

## Uso

```bash
python hola_mundo.py
```

## Convenciones aplicadas

- Nombre del repositorio en `kebab-case` minúsculo, sin acentos.
- Incluye `README.md` y `.gitignore`.
- Rama principal `main`, sin push directo.
- Ramas de trabajo con prefijos `feat/`, `fix/`, `chore/`, `docs/`.
- Commits con formato [Conventional Commits](https://www.conventionalcommits.org/).
- Cambios integrados mediante pull request.
- Sin secretos en el repositorio.
